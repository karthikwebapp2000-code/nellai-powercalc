# Nellai PowerCalc / TNEB Calc

A responsive, client-side electricity bill estimator inspired by the supplied dashboard design. It includes domestic and commercial connection types, slab breakdown, fixed charge, 7% electricity duty, savings from the domestic free slab, dark mode, and a downloadable estimate.

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.

> This is an estimate tool and is not affiliated with TANGEDCO. Confirm current tariffs and charges against your official bill before relying on the result.
